# Prueba Tecnica - Carsales

Solucion  .NET "8" para el Backend y "Angular" para el Frontend para la prueba tecnica.

## Tecnologias utilizadas

*   Backend: .NET 8 (Web API)
*   Frontend: Angular (v19+)
*   Integración: Rick and Morty API

## Estructura del Proyecto .net + angular

*   `/Backend`: API desarrollada en C# que gestiona la lógica de negocio y comunicación con servicios externos.
*   `/Frontend`: Aplicación SPA en Angular para la visualización de datos.

## ⚙️ Instrucciones de ejecución

### Backend
1. Navegar a la carpeta `Backend/`.
2. Ejecutar `dotnet restore` para instalar dependencias.
3. Ejecutar `dotnet run` para iniciar la API.
4. La API estará disponible en `http://localhost:5076`.
5. Si la API lo ejecuta como htpps, La API estará disponible en `https://localhost:7198`

### Frontend
1. Navegar a la carpeta `Frontend/`.
2. Ejecutar `npm install` para instalar las dependencias.
3. Ejecutar `ng serve` para iniciar el servidor de desarrollo.
4. Abrir `http://localhost:4200` en el navegador.
